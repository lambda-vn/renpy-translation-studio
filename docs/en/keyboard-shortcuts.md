# Keyboard shortcuts

*[Version française](../fr/keyboard-shortcuts.md)*

`F1` shows this list inside the application, on any screen.

![The shortcut list](../images/09-help-en.png)

## Anywhere

| Key | Action |
|---|---|
| `F1` | Show this help |
| `Esc` | Close the open window, otherwise clear the search |

## Review screen

| Key | Action |
|---|---|
| `Ctrl+F` | Move to the search field |
| `Ctrl+S` | Write the `.rpy` files |
| `Ctrl+Enter` | Validate and move to the next line |
| `Ctrl+Shift+Enter` | Validate and apply to every identical line |
| `Ctrl+D` | Copy the source into the translation |
| `Ctrl+M` | Flag the line for a second look |
| `Alt+↑` / `Alt+↓` | Line above / below |
| `Shift+Alt+↑` / `Shift+Alt+↓` | Previous / next file |
| `Alt+←` / `Alt+→` | Previous / next page |
| `Menu` key | Actions on the selected file |

On macOS, `Ctrl` is `⌘`, `Shift` is `⇧` and `Alt` is `⌥`.

## Menus and lists

The drop-down lists (the speaker filter, the provider and language choices,
the file actions) are opened with `Space` or `Enter` on their button, not
with the down arrow. Once a list is open, `↑` and `↓` move through it,
`Home` and `End` jump to the first and last entry, typing a letter jumps to
the next entry starting with it, `Enter` or `Space` picks the entry and
`Esc` closes the list without choosing. The file actions can also be opened
with `Shift+F10`.

## Notes

`Ctrl+Shift+Enter` is the one to remember on a game full of repeated
one-liners — a `"..."`, a `"Yes."`, a menu label that appears in twenty
places.

The shortcuts fire even while a text field has focus, so you never have to
leave the translation you are typing to validate it. In a translation
field, `Esc` leaves the field (and keeps what you typed). The review
shortcuts are inactive while a dialog is open.

The whole application is operable from the keyboard, and statuses carry a
distinct glyph and a screen-reader label rather than relying on colour.
