# Documentation

- **[English](en/README.md)**
- **[Français](fr/README.md)**

Both languages carry the same twelve pages, under the same file names, so
any page has a counterpart one folder away. Every page links to it at the
top.

```
docs/
  en/       English pages
  fr/       Pages françaises
  images/   Screenshots, shared by both languages and by the READMEs
```

## Screenshots

Every screenshot was taken on **The Question**, the sample visual novel
shipped with the Ren'Py SDK, extracted with `renpy translate french` and
filled from the French translation that same SDK ships. Nothing in them is
invented, and no third-party game is shown.

Names follow `<order>-<screen>-<lang>.png`, where `<lang>` is the language
of the interface, `en` or `fr`. The game being translated is English to
French in both.

Images live in `images/` and only there. Pages reference them as
`../images/…`, so one file serves both languages.
